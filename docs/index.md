# Inglês Entrelinhas

Um curso de inglês geral **do A1 ao C1**, construído nota por nota.

Aqui não existe "capítulo 3 que só faz sentido depois do capítulo 2". Cada
ideia mora numa **nota atômica** que se explica sozinha e aponta para as
outras. Os módulos são caminhos de leitura montados com essas notas — e é
esse mesmo material que vira o livro.
