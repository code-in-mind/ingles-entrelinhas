# Artigos — a, an, the

`a` e `an` são o mesmo artigo. A escolha entre eles **não depende da letra,
depende do som** da palavra seguinte.

- som de consoante → `a`
- som de vogal → `an`

## Exemplos

> **an** hour — escreve com "h", mas o "h" é mudo: o som é /aʊ/, vogal.
> **a** university — escreve com "u", mas o som é /ju/, consoante.
> **an** MBA — a letra "M" se lê /ɛm/: começa com som de vogal.

A regra é fonética porque a razão dela é fonética: `a apple` é desconfortável
de pronunciar. O `n` entrou para separar as duas vogais.

## `the`

`the` marca o que já é conhecido pelos dois lados da conversa:

> I bought **a** book. **The** book was expensive.

Na primeira frase o livro é novidade; na segunda, os dois já sabem qual é.
